Drop PNGs here using the exact filenames below. The Setup Guide already points at
these paths — each one shows a dashed "Screenshot coming soon" placeholder until the
file exists, then renders automatically. No code change needed.

| --- | --- |

| `03-installer-window.png` | The installer window, with the install-location / Install button |
| `04-smartscreen-warning.png` | The blue "Windows protected your PC" SmartScreen screen |
| `05-smartscreen-run-anyway.png` | After clicking **More info** — the **Run anyway** button |
| `06-start-menu.png` | UpcurvEd in the Start menu, or its desktop shortcut |
| `07-firewall-prompt.png` | The Windows Defender Firewall network-access prompt |
| `08-app-running.png` | UpcurvEd open, pinned to / visible in the taskbar |
